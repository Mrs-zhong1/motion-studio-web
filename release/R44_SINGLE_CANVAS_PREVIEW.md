# R44 — Preview-first 单画布预览重构
- 日期：2026-11-19
- 状态：代码接入与合同测试已提交，等待真实浏览器视觉验收。
## 目标
消除模板预览中“左侧介绍面板 + 右侧真实网站”的双重主视觉，让网站本身成为唯一主画布。
## 设计决策
1. 模板 iframe 铺满预览主体；介绍侧栏不再常驻。
2. 模板名称与状态留在顶部工具条。
3. 章节缩略导航移动到画布底部，作为轻量浮层。
4. 桌面/手机共用同一预览结构，仅改变视口。
5. 关闭、设备切换、章节导航、重播和使用模板保留。
6. 编辑器内部可保留专业属性区，但预览体验不采用固定左右分栏。
## 回归修复记录（2026-11-19）
- Chromium 的 R30 Cinematic 双场景试片测试发现：原试片导入按钮位于模板信息区，R44 隐藏信息区后按钮不可见。
- 已将试片导入按钮与状态提示迁移至预览画布内的浮动操作位；移动端同步调整位置。
- R44 合同测试增加断言，确保章节导航、试片按钮和状态提示都被迁入单画布。
- 这项修复尚待新一轮完整 CI 结果确认。

## 验收
- [ ] 桌面无信息侧栏；手机无信息侧栏且工具条不遮挡。
- [ ] 章节条在画布底部，可横向滚动、可切章。
- [ ] 预览关闭/使用模板/设备切换均正常。
- [ ] 三浏览器无 console/page errors。
- [ ] 导出 HTML 不受预览外壳 CSS 污染。
