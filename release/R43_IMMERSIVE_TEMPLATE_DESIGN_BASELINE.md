# R43 — Motion Studio 八套模板交互设计基准与双样板

- 日期：2026-11-19
- 基准分支：`design/r43-immersive-template-system`
- 状态：设计基准已固化；Creative Agency / SaaS 首轮交互样板已实现为导出页面增强器，待真实浏览器视觉验收。
- 适用范围：模板发现、沉浸预览、模板页面、场景内编辑和后续模板迭代。后续任何模板改版均不得绕过本文件。

## 1. 产品设计总原则

Motion Studio 是沉浸式网站模板创作工具，不是把传统后台编辑器缩小后放进模板预览的工具。

**统一编辑能力，不统一展示形式；统一操作逻辑，不统一页面构图。**

- 模板页面是唯一主画布。不得默认显示固定左侧功能面板 + 右侧预览面板。
- 导航、章节、筛选和编辑控制必须成为场景的一部分，或以就近、临时、可收起的方式出现。
- 编辑状态不得破坏模板的构图；用户选中真实内容后，在原场景中直接编辑。
- 复杂属性按需出现，不常驻占据画布空间。
- 8 套模板必须有不同的内容组织方式、浏览动作、转场节奏和视觉构图。
- 统一的是保存、撤销、素材替换、响应式、导入/导出等底层能力，不是页面外观。

## 2. 八套模板的交互合同

| 模板 | 叙事模型 | 主浏览动作 | 必须有的核心交互 | 构图禁区 |
|---|---|---|---|---|
| Creative Agency | 作品索引 / 案例叙事 | 悬停预览、点击进入案例、纵向滚动 | 项目索引联动主场景；案例章节连续切换 | 固定左右栏、独立左侧卡片面板 |
| Architecture | 空间漫游 / 建筑研究 | 纵向进入空间、热点跳转 | 外部/入口/内部/细节章节与空间热点 | 普通图片列表冒充空间浏览 |
| Cinematic | 五幕电影分镜 | 滚动驱动镜头与章节 | 连续镜头、章节时间线、reduced-motion 替代 | 同屏多个无关视觉主体 |
| Editorial | 数字杂志 / 编辑式阅读 | 纵向阅读、目录跳转 | 图文跨页、引用、注释、目录进度 | 通用全屏 Hero 套版 |
| Fashion | Lookbook / 系列浏览 | 横向滑动、拖动或逐套切换 | Look 切换、服装细节热点、系列导航 | 后台式筛选侧栏挤占图片 |
| Gallery | 策展 / 展览探索 | 网格探索、作品全屏查看 | 悬停标签、作品详情、前后作品切换 | 与其他模板相同的大图+标题骨架 |
| Product 3D | 数字展台 / 产品配置 | 旋转、缩放、材质切换、滚动揭示 | 真实 3D 操作、部件热点、低性能降级 | 无交互的大图冒充 3D 配置器 |
| SaaS | 产品任务 / 工作流演示 | 点击步骤、操作产品状态 | 至少一条可操作的 Capture → Shape → Deliver 工作流 | 只有静态 Dashboard 截图、左右功能说明栏 |

### 各模板最低交付内容

1. Creative Agency：项目索引、主视觉联动、案例章节、案例返回路径。
2. Architecture：空间章节、至少一个可操作热点、图纸/平面资料入口。
3. Cinematic：完整五幕、滚动进度、章节跳转、静态/减少动效降级。
4. Editorial：封面、专题目录、图文混排、长文阅读、引用或注释。
5. Fashion：至少一个系列、Look 切换、纵向肖像图、细节说明。
6. Gallery：作品墙、筛选或分组、全屏详情、前后切换。
7. Product 3D：可旋转模型、材质/配置切换、部件说明、无 WebGL 降级。
8. SaaS：可交互产品演示、任务步骤状态、输入/输出反馈、转化 CTA。

## 3. 两套样板：明确差异，不做换皮

### Creative Agency — Project Index / Case Story

- 视觉语言：高能排版、明亮强调色、错位项目构图、案例影像。
- 首屏：超大品牌宣言融入场景，不在左侧另建选择面板。
- 作品索引：作为场景中的横向/网格项目目录，悬停改变选中态，点击滚动进入对应案例章节。
- 案例内容：沿用同一主场景与章节连续叙事；不叠加无关 iframe 小演示。
- 导航：项目编号和轻量状态信息融入页面。
- 手机：项目目录两列重排，触控点击进入；不压缩成左右栏。

### SaaS — Interactive Workflow / Product Demo

- 视觉语言：浅色产品工作台、深色产品演示窗口、清晰的数据/状态层级。
- 首屏：先说明产品价值，再让用户直接操作工作流。
- 工作流：Capture → Shape → Deliver 三步切换；点击步骤更新说明、界面状态、进度和 CTA。
- 布局：演示模块在页面主轴内全宽展开，说明和模拟界面作为同一组件内部的响应式构成；不做固定左右编辑器。
- 手机：说明与模拟界面纵向排列，步骤按钮可触摸。
- 后续：接入模板真实可编辑图层/组件，而不是长期保留静态演示假象。

## 4. 预览与编辑状态规范

### 沉浸预览
- 模板实际导出 HTML 作为唯一预览内容，不允许用截图冒充交互。
- 桌面/手机切换、重播、章节跳转和使用模板保留在最小工具条。
- 模板信息按需浮出，不永久占据画布。
- 不能同时出现重复标题、重复导航或互相矛盾的演示场景。

### 场景内编辑
- 选择真实标题/图片/章节后，就地显示编辑入口。
- 图片替换、文本编辑和章节编辑直接作用于画布内容。
- 复杂参数用临时浮层或可收起的专业模式。
- 不以常驻左右侧栏作为默认编辑入口；如保留高级属性面板，必须允许收起并保持画布为视觉主体。

## 5. 参考模式与借鉴边界

- 作品索引与悬停预览：参考 Obys 等工作室的项目发现方式。
- 滚动叙事：参考 Apple 产品页的章节推进和镜头节奏。
- 空间/实验性交互：参考 Resn、14islands、Bruno Simon 的交互探索，但按设备能力渐进增强。
- 编辑式阅读：参考数字杂志的跨页、字体层级和图片节奏。
- Lookbook：参考时装系列的横向浏览和大幅肖像图。
- SaaS 产品演示：参考产品导览/交互式 demo，而非静态 dashboard 拼贴。

只借鉴交互原则和信息架构，不复制专有源码、品牌资产、独特视觉作品或未经核验的素材。

## 6. 硬性验收门槛（任何一条失败即视觉/交互 HOLD）

- [ ] 8 套模板的叙事模型、主浏览动作和核心交互均有差异。
- [ ] 不出现固定左侧功能面板 + 右侧预览面板作为默认展示结构。
- [ ] 不得通过缩窄、透明化、改色或隐藏边框伪装“融合”。
- [ ] 导航和控制与场景有明确关系，不遮挡主要内容。
- [ ] 每套模板至少有一个有意义、可实际操作的核心交互。
- [ ] 桌面鼠标、键盘和移动触控均可完成主要任务。
- [ ] prefers-reduced-motion 下有可用替代，不依赖动画才能读懂内容。
- [ ] 编辑、保存、重新打开、HTML 导出保持内容和交互一致。
- [ ] 无重复标题、无冲突的双重视觉主体、无不可访问的浮层。
- [ ] Chromium / Firefox / WebKit 分别执行对应范围的真实浏览器验收；不能把 Chromium 专项测试描述为三浏览器全量通过。
