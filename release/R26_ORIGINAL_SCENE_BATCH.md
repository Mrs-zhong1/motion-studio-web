## Remaining blocking steps

2. In Actions > R26 Original 2K Scene Production > Run workflow, choose `generate`, template `ALL`, limit `33`; explicitly authorize image billing and acknowledge provider terms. For smaller initial tests, choose limit `2`.
3. Review the staged PNG-derived JPEG originals in the Actions artifact; reject apparent artifacts, incoherent subjects or poor typography-safe composition. The code validates pixel size, not professional art direction.
4. Use the existing `stage9/replace_ai_chapters_r25.py` batch importer with `replacement.json` from the staging artifact; `--apply` only after approval. Rebuild the strict AI-only HTML and run all three browser E2E engines, screenshots and deployment integrity gates.
